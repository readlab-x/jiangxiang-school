## 为什么需要这么多规矩

先说清楚一件事：**这些制度的首要目的不是提高骗术，是防止泄密。**

一门手艺能不能持续存在，取决于两件事——**做的人够不够多，外人知不知道**。江相派两项都要：广纳门徒（相命先生、神棍、庙祝、道士、和尚、卖艺者、三合会人士），同时严密封锁技术传承。

于是产生了看似矛盾的现象：**对内极度分层，对外高度伪装。**

## 官阶制度

> 江相派之阶层制度是以首领称宰相或大学士，次以状元，榜眼，探花，翰林，进士，举人等顺序顺排地位之。

| 职位 | 身份 |
| --- | --- |
| 大学士 / 宰相 | 首领，对外称"大师爸" |
| 状元、榜眼、探花、翰林 | 得师门真传者 |
| 进士、举人 | 未得真传者 |

**得真传的资格门槛极高。** 据博客园所录：

> 出师当相即可收徒，但收授真传弟子要探花以上才可，亦要本门师兄弟认可才可收授，并得带领该徒会见大学士及各师叔伯请训。

即：**只有核心层才能培养核心层**。同时，秘本"一般不会传给自己儿女"，理由是"表明一种公正，以及不希望自己的子女行此道"。

首领称"大师爸"，对外称"大相士"，因其大都自称神之使者，故亦被称大神棍——**又被内行人直称"江湖之狐"**。

## 六条门规

> 一、不得泄露门派之秘密。
> 二、失手时不得吐露所做的事物。
> 三、失手时不可出卖同伙。
> 四、只许骗钱、不得骗色。
> 五、所骗对象的钱是要不义之财。
> 六、不许整死顾客，以维护团体安全。

逐条看，第1–3条是保密纪律，第4–6条是**行为准则**。值得注意的是后三条：

- **第4条**"只许骗钱、不得骗色"把"拆白"（骗财骗色）和"拐子"（离人骨肉）排除在外。
- **第5条**确立了目标筛选的道德标准——只有骗"不义之财"。
- **第6条**"不许整死顾客，以维护团体安全"——理由写得很坦率：**不是为了受害者，是怕闹出动静影响组织**。

这套自我约束的动机完全是组织利益导向的，但它客观上限制了江相派的危害程度。这也是理解这类组织的一个关键角度：**他们比警察更不希望事情闹大。**

## 叩门仪式

江相派在市井相遇时会用一套问答确认彼此身份。这套仪式是**反冒称的**——防止外人混入，也防止同门冒充。

> **问：**谁点您出来当相的。
> **答：**您的师爸贵姓。（此句如答错即知非同门中人）
> **问：**您的师爸贵姓：
> **答：**姓方。（此时方可反问，但亦须答以姓方才属门派中人）
> **问：**您是什么出身。
> **答：**在下是举人。（或进士等，此指表示同派不同门，或同派同门，或答探花则辈份又分上下而论）
> **问：**请问有何凭证：
> **答：**有诗为证。（此时可反问行规，又如被反问时得立即斟茶并用三个指头拈茶杯递茶，并自我介绍，对方得马上同法回敬一杯茶，并将茶杯以放于桌面之左角或右角代表辈份的高低）
> **问：**既有诗为证可否赐教一二。（如对方答不出即如其为冒犯之人，便答以「在下是空子请多包涵」，便知对方为不同派门中人）
> **答：**祖师遗下三件宝，众房弟子得真传，乾坤交泰离济坎，江湖四海显名声，第ＸＸ传传到我，禀承师父命闯江湖，出身原是ＸＸ院，如今分房ＸＸ郎。

系歌的结构是固定的：

```
祖师遗下三件宝，众房弟子得真传。
乾坤交泰离济坎，江湖四海显名声。
第 XX 传传到我，禀承师父命闯江湖。
出身原是 XX 院，如今分房 XX 郎。
```

注意"乾坤交泰离济坎"对应四房（乾坤坎离）的组织结构，"第XX传"是代数，"XX院"是出身等级，"XX郎"是所属房。

**茶礼是第二重身份验证。** 三指拈杯、以茶杯放置位置表示辈份高低——这是一个纯物理的、无需言语的暗号系统。

## 门规的处罚

> 犯行规得被驱逐出派门之外。

并且有实证案例：维基词条记载，香港的**傅吉臣**曾用"扎飞"手段骗他人之妾为己妾，违背同门规矩，在何立庭死后不能接任掌门。

**这是文献中唯一一条"门规被实际执行"的记录**，很有价值——它说明这套制度不是摆设。

## 设计的可借鉴性

抛开道德问题，这套组织设计在**信息安全管理**上有值得借鉴之处：

| 措施 | 目的 |
| --- | --- |
| 秘本口传、不准笔录 | 减少物理载体 |
| 只传嫡系、不传子女 | 控制知情人范围 |
| 全篇黑话 | 外人读来如天书 |
| 叩门系歌 | 双向验证，防冒名 |
| 茶礼暗号 | 无言验证 |
| 门规 + 逐出机制 | 建立惩罚可信度 |

**最后一条最关键。** 一套惩罚如果不可执行，就只是装饰。江相派有明确的逐出案例，这才让"不得泄密"具备了实际约束力。

这也是老千集团与临时团伙的根本差别：**前者建立制度，后者只靠默契。**

## 三栏布局修复（用户反馈"布局都乱了"）

**根因：嵌套 grid 失效。** 原结构 `.reader`(三列) > `.rd-flow`(两列) > `.rd-row`(三列)。`.rd-row` 是 `.rd-flow` 的子元素，作为单个 grid item 只能占一列——它内部写的 `grid-template-areas: 'no orig note'` 完全没生效，三栏塌成两栏，注解被挤到长文下方。

**修法：用 `display: contents` 摊平嵌套。**
- `.rd-flow { display: contents }` — 让三元素直接成为外层 grid 子项
- `.rd-row` 已不用（`<>` 片段被 Astro 编译掉），三个 div 直接平铺
- 外层 `.reader` 改四列：`150px 30px minmax(0,1fr) 300px`（左栏 / 序号 / 中栏 / 注解栏）
- 各元素 `grid-column` 显式定位，`column-gap: 0`，靠 padding 留白

**教训：CSS Grid 不能靠嵌套"叠"出列。** 想要多栏对齐，要么全程单一 grid + `grid-column`，要么用 `display: contents` 消层级。嵌套 grid 的子元素只在自己的父级 grid 里有列定义。

**同时清理了注解里的英文残留**（9 处）：`silence`→找话说、`family`→我家的事、`dramatic`→耸人听闻、`target`→女性目标、`unmet`→未被满足、`inorganic`（坏数据）→入门先观来意、`employed`→手下有人的。新增 `scripts/check-en.py` 检测。
